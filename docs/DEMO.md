# 妙语 MouseTalk：一分钟演示

目标输出文件：`~/Movies/MouseTalk/MouseTalk-0.6.0-demo.mov`

## 录制前准备

1. 把与当前源码一致、显示名为“妙语 MouseTalk”的 0.6.0 构建安装到 `/Applications/MouseTalk.app`，退出旧进程后重新打开。
2. 在系统设置中确认“输入监控”和“辅助功能”均已授权，妙语状态显示“已就绪”。
3. 豆包输入法和妙语都设置为同一个单键快捷键；优先使用“右 Option + 标准模式”。兼容模式必须先确认不会一次点击触发两次。
4. 绑定一个侧键为“语音”、另一个侧键为“发送”。若要展示连续删除，可把滚轮中键绑定为“删除”。
5. 清除 Logi Options+ 中这些按钮的动作，或录制时退出 Logi Options+，避免一个物理按键被两套软件同时处理。
6. 运行 `./scripts/demo-preflight.sh`。它不会发送按键；自动检查通过后，仍需手动完成下面的真机彩排。

## 必须先通过的真机彩排

- 第一次按语音侧键只开始一次录音；第二次按只结束当前录音，不立刻开始下一轮。
- 说出“请帮我把这个需求拆成三个步骤”，文字进入当前 Coding Agent 输入框。
- 按发送侧键后消息只发送一次。
- 打开模型、Thinking 和 Codex／ChatGPT 菜单，确认普通左键仍能点击。
- 若展示删除：单击删除一个字符，按住连续删除，松开后立即停止。
- 关闭设置窗口后菜单栏图标仍在，绑定继续生效。

任一项失败就停止录制并记录：macOS 版本、鼠标型号、按钮编号、豆包快捷键、妙语模式和失败现象。

## 60 秒镜头顺序

- **0–8 秒：**展示“妙语 MouseTalk”设置页、两项权限为已开启、状态为已就绪。
- **8–18 秒：**展示右 Option、语音按钮和发送按钮的配置，不在镜头中重新绑定。
- **18–38 秒：**切到 Coding Agent 输入框，按语音侧键，说出示例句，再按同一侧键结束；镜头保持在文字结果上。
- **38–48 秒：**按发送侧键，展示消息被提交。
- **48–55 秒：**可选：用中键单击删除和按住连续删除；若未稳定验收则跳过。
- **55–60 秒：**展示菜单栏老鼠图标，并以“本地运行、不录音、不读取输入内容”收尾。

录制建议使用 macOS `Shift-Command-5`，只录应用相关区域，关闭通知并避免出现私人输入内容。
